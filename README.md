# Магазин обуви «Шаг»

Учебный проект интернет-магазина обуви (учебная практика, пары 5–30).

Настольное приложение учёта и продаж: каталог товаров, поиск/фильтрация/сортировка, корзина и оформление заказа, работа с остатками на складе.

## Стек

- **Приложение:** C# (Windows Forms)
- **База данных:** MySQL
- **Схемы/диаграммы:** draw.io, MySQL Workbench (ER-модель)

## Структура репозитория

```
├── README.md
├── .gitignore
├── docs/
```

## Данные

Импортные данные (товары, пользователи, заказы, пункты выдачи) перенесены из эталонных файлов ДЭ в 10 нормализованных CSV в папке `db/import/`:

| Файл | Строк | Назначение |
|------|-------|------------|
| categories.csv | 2 | категории товаров |
| manufacturers.csv | 6 | производители |
| suppliers.csv | 2 | поставщики |
| products.csv | 30 | товары |
| roles.csv | 3 | роли пользователей |
| users.csv | 10 | пользователи |
| pvz.csv | 36 | пункты выдачи заказов |
| orderstatus.csv | 2 | статусы заказа |
| orders.csv | 10 | заказы |
| prodorders.csv | 20 | строки заказов (состав) |
